hypeFilestore
=============
![Elgg 7.x](https://img.shields.io/badge/Elgg-7.x-orange.svg?style=flat-square)

File and image handling utilities for Elgg.

Utility plugin that:
* Handles file uploads
* Manipulates images
* Serves icon files

## Compatibility

| Plugin version | Elgg version |
|---|---|
| current | 7.x |
